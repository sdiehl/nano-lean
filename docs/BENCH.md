# Benchmarks

`benches/kernel.rs` checks declarations on the value core in the same loop as `nl-fast -j 1` and reports instructions, cycles, wall and user time, and exact arena bytes per bench. The suite in `benches/suite.toml` covers seven synthetic micro files in `benches/micro` (beta, iota, literals, delta, let chains, eta, proof irrelevance, generated by `gen.py`), real Init, Std and Mathlib declaration closures, lean-kernel-arena perf cases, and all of Init and Std. `benches/fixtures.sh` builds the non-micro inputs into the ignored `benches/fixtures`, `benches/compare.py [BASE] [FILTER]` runs a revision against the working tree as A B B A under `.local/benchmark.lock`, and `cargo test` checks every micro bench once. Instructions and arena bytes are the signal, and wall deltas under the noise column are not.

```sh
cargo bench --bench kernel                        # whole suite
cargo bench --bench kernel -- micro/              # names containing micro/
cargo bench --bench kernel -- --list              # benches and whether their inputs exist
cargo bench --bench kernel -- --save before       # keep results in target/nl-bench/before.json
cargo bench --bench kernel -- --baseline before   # diff against them
cargo bench --features vstats --bench kernel      # add value-core counters per bench
```
